# Prompt — Ideias de Pins (Pinterest)

Crie 10 ideias de Pins para promover **{NOME_DO_PRODUTO}**, direcionando para a pre-sell page.

**Regras:** formato vertical 1000x1500 ou quadrado 1000x1000; texto grande e legível na imagem;
SEO no título, descrição e nome do arquivo; boards temáticos.

**Temas:** Review ("Vale a pena? Review completo"), Benefícios ("5 benefícios de..."),
Comparação ("X vs. Y"), Dica ("Como X resolveu meu problema de {DOR}").

Formato de saída por ideia:
{ "titulo_pin": "até 100 caracteres",
  "descricao": "até 500 caracteres com palavras-chave",
  "texto_na_imagem": "destaque",
  "sugestao_imagem": "antes/depois, produto em uso, etc." }
