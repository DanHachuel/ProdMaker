# Prompt — Pre-Sell Page (Afiliado)

Crie uma página de pré-venda (pre-sell) em **um único arquivo HTML** (CSS e JS embutidos),
mobile-first, estilo limpo e profissional, foco em convencimento.

**Produto de terceiros:** {NOME_DO_PRODUTO} · link de afiliado: {LINK_AFILIADO}

**Estrutura obrigatória:**
1. Título: "O que você precisa saber sobre {NOME_DO_PRODUTO}"
2. 3–5 benefícios principais (com ícones)
3. Prova social: placeholders de prints de resultados
4. Comparação: Produto vs. Alternativas (tabela)
5. FAQ: 5 perguntas respondendo objeções
6. CTA: "Clique aqui para saber mais" com link para {LINK_AFILIADO}

**Regras técnicas:** elemento de urgência discreto (contador ou aviso de oferta);
incluir o snippet de pixel do ProdMaker (`{PIXEL_SNIPPET}`) antes de `</body>`.
Retorne APENAS o HTML.
